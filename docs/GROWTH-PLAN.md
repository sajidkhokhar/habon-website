# 30-day organic growth plan

**Principle:** a brand-new `pages.dev` site has no authority. Realistic early wins come from long-tail pages, useful tools people link to, and the App Store listing itself. Expect weeks, not days, before anything ranks.

## Week 1: foundation
- Deploy, verify Search Console, submit sitemap, request indexing for 10 key URLs.
- Install Cloudflare Web Analytics (and GA4 if desired). Confirm `app_store_click` events.
- Add the same website URL to the App Store listing's **Marketing URL** and **Support URL** (App Store Connect). This is a legitimate, high-value link from apple.com.
- Check `site:habon.pages.dev` weekly to see pages enter the index.

## Week 2: link-worthy assets
- Add A5 and yearly printable sizes, and a CSV/XLSX tracker template (autocomplete shows heavy Google Sheets/Excel demand).
- Publish "Habit tracker for Notion/Google Sheets" guide pointing to those downloads.
- Add a "habit tracker for ADHD" page only if it can be written carefully with evidence and no medical claims.

## Week 3: earn first backlinks (with approval)
- AlternativeTo listing; SaaSHub listing; Product Hunt scheduled launch for the free tools + app.
- Send 10 personalised emails to productivity/habit bloggers offering the printable generator.
- Indie Hackers build story.

## Week 4: measure and double down
- Search Console: queries with impressions but no clicks; improve titles/descriptions for those.
- Pages with impressions at positions 8-20: add depth, FAQs and internal links.
- Publish 2 articles targeting the queries that show impressions, not guesses.
- Review which tools get use and which get App Store clicks.

## Ongoing
- 1-2 quality articles a month. Update old ones with real changes and dates.
- Get real App Store ratings by prompting happy users inside the app (not on the website). Only then add `aggregateRating` markup, never before.
- Consider a custom domain later (about $10 a year) as an optional paid upgrade; not required.
