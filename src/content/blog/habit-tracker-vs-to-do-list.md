A to-do list and a habit tracker both involve checking things off, which is why people mix them up. They solve different problems, and using the wrong one is a common reason for frustration.

## The core difference

- A **to-do list** is for things you do **once**. Pay the bill. Book the dentist. Send the report. When it is done, it leaves the list.
- A **habit tracker** is for things you do **repeatedly**. Walk, read, stretch, take medication. The item never leaves. What matters is the pattern over time.

## Side by side

| | To-do list | Habit tracker |
|---|---|---|
| Purpose | Finish tasks | Build and measure behaviors |
| Items | One-off | Recurring |
| Success looks like | An empty list | A steady pattern |
| Key numbers | Items done | Streaks, completion rate |
| Failure mode | Endless, growing list | Too many habits, broken streaks |

## What goes wrong when you mix them

- **Habits on a to-do list** get ticked, then reappear tomorrow, which is tiring and gives you no history. You cannot see that you have done them 24 of the last 30 days.
- **Tasks in a habit tracker** clutter the screen and pollute your stats. "Call the plumber" is not a habit.

## When to use which

Use a **to-do list** for deadlines, errands and projects. Use a **habit tracker** for daily or weekly behaviors you want to become routine. Use a **routine** when habits belong in a sequence, such as a morning or evening flow. See the [daily routine planner](/daily-routine-planner/).

## Where they overlap

Some things start as tasks and become habits. "Clear my inbox" might be a one-off task today and a daily 10-minute habit next month. When something recurs, move it to the tracker.

## A simple combined system

1. Keep **two to five habits** in a tracker.
2. Each evening, write **three tasks** for tomorrow on a to-do list.
3. Once a week, review both: which tasks slipped, which habit slipped.

Try the [online habit tracker](/online-habit-tracker/) for habits and the [weekly habit planner](/weekly-habit-planner/) to view the week. For the method, see [how to track habits effectively](/blog/how-to-track-habits-effectively/).

## A note on apps

Some apps combine tasks and habits, and others keep them separate. Habon is a habit tracker and routine planner and does not try to be a task manager. If you want both, pair it with whichever to-do app you already use.
